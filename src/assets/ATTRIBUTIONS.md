- `tasting-still-life.png` — original generated image, created 2026-08-08. Generic cellar tasting still life; the bottle is deliberately unlabelled.

- `winemaking-journey.png` — original generated educational cellar scene, created 2026-08-08. It depicts generic vessels and process stages without producer claims.

- `region-mediterranean-vines.jpg` — original generated landscape, created 2026-08-08. Generic warm Mediterranean bush-vine setting.

The application imports web-optimised JPEG derivatives of all generated imagery. The first five original PNG masters remain in the repository for future art direction; the newer generated masters remain in the local image-generation output store.

Map tiles are provided at runtime by OpenStreetMap and retain visible on-map attribution.
